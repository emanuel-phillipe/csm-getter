Projeto desenvolvido por conta própria, com foco nos alunos do Colégio Santa Maria Minas. Neste script, o usuário introduz o login e senha usados no site da instituição e, automaticamente, todas as matérias, avaliações e atividades e suas respectivas notas são transmitidas para o usuário em um arquivo JSON.

Por meio do terminal, o usuário também consegue conversar com o ChatGPT 4o em relação aos seus resultados escolares. Por instância: "Qual foi a minha nota na Avaliação Especial de Ciências da Natureza?"; "Até agora, qual é o somatório das minhas notas em Educação Financeira?"; "Eu tirei mais de 50% na Avaliação I de Ciência do Direito?".

> OpenAI API - Transmissão do arquivo JSON e "conversa" com o boletim

> Selenium - Acesso ao site da escola automático e download da página HTML das avaliações

> BeautifulSoup - Processamento do arquivo HTML para o acesso aos dados
